  ВОПРОС 1: "ГДЕ ЗАГОЛОВОК ВРУЧНУЮ В INSOMNIA?"
═══════════════════════════════════════════════════════════════

ДЕМОНСТРАЦИЯ:

1. Открыть Insomnia

2. Выбрать запрос GET /api/applications

3. Перейти на вкладку "Header" (не Auth!)

4. Нажать "+ Add Header"

5. ВРУЧНУЮ ввести:
   
   ┌─────────────────────────────────────────┐
   │ Name:  Authorization                    │
   │ Value: Bearer eyJhbGc...{полный_токен}  │
   └─────────────────────────────────────────┘

6. Отправить запрос

ПОКАЗАТЬ ПРЕПОДАВАТЕЛЮ:
  ✓ Вкладка "Header" в Insomnia
  ✓ Ручной ввод "Authorization"
  ✓ Формат: "Bearer " + токен (с пробелом!)

═══════════════════════════════════════════════════════════════
  ВОПРОС 2: "JWT ГДЕ В REDIS? JWT ЗАЧЕМ СЕССИЯ?"
═══════════════════════════════════════════════════════════════

ПРАВИЛЬНЫЙ ОТВЕТ:

  JWT токены - STATELESS (не требуют сервера).
  Сессии НЕ НУЖНЫ для JWT!
  
  Redis используется ТОЛЬКО для:
    ✓ Blacklist отозванных токенов (logout)
    ✓ TTL = автоматическое удаление

─────────────────────────────────────────────────────────────

ДЕМОНСТРАЦИЯ (ПРОСТОЙ redis-cli, БЕЗ СКРИПТОВ):

1. Открыть терминал:
   $ redis-cli

2. Показать содержимое Redis (пусто):
   127.0.0.1:6379> KEYS "lab4_service.*"
   (empty array)

3. Объяснить: "Redis пустой, т.к. JWT не хранится в базе"

4. Залогиниться через Swagger:
   POST /api/users/login
   {"username": "user1", "password": "password123"}
   
   Получить JWT токен

5. Снова проверить Redis (всё ещё пусто):
   127.0.0.1:6379> KEYS "lab4_service.*"
   (empty array)

6. Объяснить: "JWT в Redis НЕ сохраняется! Только blacklist."

7. Выполнить logout через Swagger:
   POST /api/users/logout
   Authorization: Bearer {токен}

8. Показать blacklist в Redis:
   127.0.0.1:6379> KEYS "lab4_service.jwt_blacklist.*"
   1) "lab4_service.jwt_blacklist.eyJhbGc..."

9. Показать содержимое blacklist:
   127.0.0.1:6379> GET "lab4_service.jwt_blacklist.{токен}"
   "1"

10. Объяснить TTL:
    127.0.0.1:6379> TTL "lab4_service.jwt_blacklist.{токен}"
    (integer) 86395  (остаток времени жизни)

─────────────────────────────────────────────────────────────

ПОКАЗАТЬ ПРЕПОДАВАТЕЛЮ:
  ✓ Простой redis-cli (не скрипт!)
  ✓ KEYS "lab4_service.*" - пусто до logout
  ✓ После logout - токен в blacklist
  ✓ TTL токена в Redis

═══════════════════════════════════════════════════════════════
  КОНЦЕПЦИЯ ДЛЯ ОТВЕТА ПРЕПОДАВАТЕЛЮ
═══════════════════════════════════════════════════════════════

JWT = JSON Web Token
  ✓ Самодостаточный токен (user_id, username, is_moderator)
  ✓ Подписан секретным ключом (HS256)
  ✓ Stateless - не требует проверки в БД
  ✓ Содержит время истечения (exp)

Redis Blacklist
  ✓ Используется ТОЛЬКО для отзыва токенов
  ✓ При logout токен добавляется в blacklist
  ✓ Middleware проверяет токен в blacklist
  ✓ TTL = время жизни JWT (24 часа)
  ✓ Автоматическое удаление после истечения

ВЫВОД:
  JWT не требует сессий!
  Redis = только blacklist для logout.
  Это стандартная практика для JWT токенов.
