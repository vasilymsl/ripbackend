Если хочешь использовать свои картинки:

1. Через Swagger (требуется модератор):
   POST /api/credits/{id}/image
   Authorization: Bearer {moderator_token}
   Body: multipart/form-data, file field "image"

2. Или обновить URL в БД:
   docker exec lab4-dev-postgres psql -U myuser -d credits \
     -c "UPDATE credits SET image_url = 'https://example.com/my-image.jpg' WHERE id = 1;"

3. Или загрузить в MinIO и указать имя файла:
   docker exec lab4-dev-postgres psql -U myuser -d credits \
     -c "UPDATE credits SET image_url = 'my-credit.png' WHERE id = 1;"
