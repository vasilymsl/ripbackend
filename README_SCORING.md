# 🎯 Lab4 - Оценка кредитоспособности по скоринговой модели

## ✅ Что реализовано

**5 услуг оценки кредитоспособности:**

1. **Базовый скоринг заемщика** (точность 87%) - 2 дня
2. **Анализ транзакций** (точность 92%) - 10 дней  
3. **Залоговый скоринг** (точность 90%) - 1-3 дня
4. **Ипотечный скоринг** (точность 94%) - 120 дней
5. **Скоринг самозанятых** (точность 89%) - мгновенно

## 📝 Структура БД

**Таблица `credits` (услуги):**
- `title` - название услуги
- `icon` - путь к файлу (например, `1.PNG`)
- `image_url` - путь к файлу (дубликат для совместимости)
- `type` - тип услуги
- `percent` - точность скоринга (в процентах)
- `term_from`, `term_to` - сроки оценки (в днях)
- `description`, `feature1-3` - описания
- `status` - статус (`active`)

**Таблица `applications` (заявки):**
- Поля скоринга: `credit_score`, `scoring_result`, `max_credit_amount`, `rejection_reason`

## 🎯 Формула скоринга

```
DTI = ((Обязательства + Ежемесячный платеж) / Доход) × 100%

Критерии:
- DTI ≤ 30%  → Отличная кредитоспособность (скор 800-1000)
- DTI 30-40% → Хорошая кредитоспособность (скор 600-799)
- DTI 40-50% → Удовлетворительная (скор 400-599)
- DTI > 50%  → Отклонено (скор 0-399)

MaxCredit = (Доход - Обязательства) × 0.4 × 12 месяцев
```
