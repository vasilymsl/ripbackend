  2. "JWT ГДЕ В REDIS? JWT ЗАЧЕМ СЕССИЯ?"
═══════════════════════════════════════════════════════════════

ОТВЕТ:
  "JWT токены - stateless, они не хранятся на сервере.
   Redis используется ТОЛЬКО для blacklist отозванных токенов.
   
   Сейчас покажу:
   
   1. Redis пустой (до logout)
   2. Логинюсь - Redis всё ещё пустой
   3. Делаю logout - токен попадает в blacklist
   4. Проверяю Redis - вижу отозванный токен"

ПОКАЗАТЬ В redis-cli:
  
  $ redis-cli
  
  # До logout:
  127.0.0.1:6379> KEYS "lab4_service.*"
  (empty array)
  
  # После logout:
  127.0.0.1:6379> KEYS "lab4_service.jwt_blacklist.*"
  1) "lab4_service.jwt_blacklist.eyJhbGc..."
  
  127.0.0.1:6379> GET "lab4_service.jwt_blacklist.{токен}"
  "1"
  
  127.0.0.1:6379> TTL "lab4_service.jwt_blacklist.{токен}"
  (integer) 86395

КОНЦЕПЦИЯ:
  ✓ JWT = самодостаточный токен (user_id, username, is_moderator)
  ✓ Не требует проверки в БД при каждом запросе
  ✓ Redis blacklist = для отзыва токенов при logout
  ✓ TTL = время жизни JWT (24 часа)
